# PRD 模板 · 标准版（standard）

> 档位定位：默认兜底档。选档依据：三维度评分（技术复杂度 / 风险影响 / 范围广度，各 0-10）均值 4-7 且风险维 <8 自动选本档；评分依据锚定上游已确认产物（澄清要点复杂度与约束、结构模块数与集成点、原型页面数），不凭空打分；用户可一键切换三档任一。
> 页数预算：3-5 页。本文件是「给 AI 的生成骨架」：{{}} 为占位符，由上游已确认产物与用户对话填充。
> 输入基准：已确认结构（模块-页面映射表、核心流程图）+ 已确认原型（页面清单）+ 澄清要点表 + 可选调研产物（05-analysis/）。结构或原型未确认不得进入生成。
> 生成约束（三档通用，违反任一即不通过）：① 功能需求与映射表及原型一一对应，结构与原型中不存在的功能不得写入；② 引用调研事实标注出处文件路径，不引入上游输入之外的新假设；③ 数据指标数字 100% 来自用户，Agent 不建议、不编造任何具体数值；④ 结构或原型回退修改并重新确认后，PRD 自动标「已过期」并分级标注影响范围；⑤ 每个页面必配 ASCII 线框图（text 代码块），与映射表及原型页面清单一一对应，漏任一页面即不通过。
> 骨架：八章不合并，每章按生成要点展开为成段内容，深度介于 lean 与 full 之间。
