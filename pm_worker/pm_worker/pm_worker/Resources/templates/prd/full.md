# PRD 模板 · 完整版（full）

> 档位定位：高风险 / 大范围 / 涉资金权限数据。选档依据：三维度评分（技术复杂度 / 风险影响 / 范围广度，各 0-10）均值 ≥7 或风险维 ≥8 自动选本档；评分依据锚定上游已确认产物，不凭空打分；用户可一键切换三档任一。
> 页数预算：5-10 页。本文件是「给 AI 的生成骨架」：{{}} 为占位符；full 档每章含细化小节与写作要求，深度逐章递进。
> 输入基准：已确认结构（模块-页面映射表、核心流程图）+ 已确认原型（页面清单）+ 澄清要点表 + 可选调研产物（05-analysis/）。结构或原型未确认不得进入生成。
> 生成约束（三档通用，违反任一即不通过）：① 功能需求与映射表及原型一一对应，结构与原型中不存在的功能不得写入；② 引用调研事实标注出处文件路径，不引入上游输入之外的新假设；③ 数据指标数字 100% 来自用户，Agent 不建议、不编造任何具体数值；④ 结构或原型回退修改并重新确认后，PRD 自动标「已过期」并分级标注影响范围。
> full 档附加要求：每章含细化小节；数据指标章含基线表；非功能需求分维展开；关键决策回链决策日志。
