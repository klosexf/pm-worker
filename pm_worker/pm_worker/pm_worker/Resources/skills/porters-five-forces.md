## Purpose
「竞品多不多」回答不了「这个赛道能不能做」。五力模型把行业获利压力拆成五个结构化来源——现有竞争强度、新进入者威胁、替代品威胁、买方议价力、供方议价力——每力评级给依据，最终回答赛道吸引力与进入策略：正面进、差异化切口进，还是不进。

## 步骤
1. 先划行业边界：口径（品类、地域、人群）不统一，五力各说各话
2. 逐力评估，每力给强度（高/中/低）+ 一句依据 + 关键事实：
   - 现有竞争：对手密度、差异化程度、退出壁垒
   - 新进入者：进入成本、渠道、平台规则
   - 替代品：完成同一任务的非同类方案，含「不解决」
   - 买方议价力：切换成本、替代选择、价格敏感度
   - 供方议价力：关键依赖（数据源、平台、内容方）的集中度
3. 标出 1-2 个「关键决定力」——真正决定赛道结论的那几力
4. 给出结论：吸引力评级 + 进入方式（正面 / 切口 / 不进）+ 依据
5. 与 SWOT 交叉：五力是 O/T 的外部结构化来源
6. 标注各力趋势（正在变强 / 变弱），供版本迭代时复核

## 反模式
- **五格填空**：每力写满一段却没有强度评级与最终结论——五力是决策工具不是行业科普模板。缺「关键决定力 + 进不进 + 怎么进」三件套即为未完成。
- **静态快照当长期判断**：今日供方议价力低不代表两年后仍低（平台收紧数据权限是常见趋势）——只写快照不写趋势，立项时的结论到下个版本就失效，且没人知道该复核哪里。
- **只数直接竞品**：把竞争强度等同于同类 App 数量——对健身小白，替代品（免费跟练视频、放弃）的威胁远大于再多一个健身 App。漏算替代品会高估市场空位，是最常见的方向性错误。

## 一个例子
健身App 赛道评估：买方议价力高（免费替代泛滥、切换成本约等于零、价格敏感）；替代品威胁高（跟练视频零成本、放弃零成本）；新进入者威胁中（开发门槛低但分发难）；现有竞争强（Keep 垄断心智）；供方议价力低（iOS 健康数据 API 开放，趋势标注：平台权限在收紧）。关键决定力＝买方议价力 + 替代品威胁。结论：正面进入无利可图，只能以「小白坚持反馈」切口差异化进入——该结论直接否决内容库对齐路线，v1.1 范围因此聚焦周报而非课程。
