## Purpose
高保真原型不是线框加点颜色，而是让用户把页面当「可上线产品」判断——不仅看着真，还要**点得动**：视觉保真给真实质感，交互保真让核心流程从头走到尾。先定令牌再逐页实现，每个可点元素接上真实行为，交付前过 AI 味 + 点击走查双自检。

## 步骤
1. 先定设计令牌：`:root` CSS 变量写全——主色/强调色/中性色阶/字阶/间距（4/8px 基数）/圆角（全页一套）/阴影（染底色相、弥散低透明，如 `0 20px 40px -15px rgba(0,0,0,.05)`）
2. 配色 60/30/10：底色 60-70%、卡面 20-30%、主色 8-12%；强调色全页唯一锁定；中性色微染品牌色相（禁死灰），卡面相对底色微暖/微冷偏移
3. 排印纪律：display 收字距（-0.02em）、行高 1.6-1.7、行宽 ≤65ch、数字 `tabular-nums`、首屏 ≤3 种字型层级
4. 组件四态：交互件给 hover/active/focus/disabled——hover 用 transform 上浮禁布局位移，active scale(0.98)；加载态用骨架 shimmer 禁圆形 spinner
5. 交互接线（与视觉同权重，未接线不交付）：**凡长得像能点的元素必须真能点**，内联 vanilla JS——导航/CTA/卡片点击切页（多屏 display 切换，禁 `href="#"` 死链）；Tab/分段切换内容并高亮；弹窗/抽屉/下拉开得起关得掉（遮罩/Esc/关闭钮其一）；开关勾选点击翻转、输入框聚焦可见；提交/保存/删除给 Toast 或状态变化，禁点了没反应；纯装饰改非交互样式，禁伪按钮
6. 真实感素材：禁外链图片——内联 SVG 场景块、CSS 渐变、头像首字母；数据用有机值（47.2%、+1 312 847-1928），禁 Lorem/John Doe
7. 交付双自检：AI 味五项（紫黑底/暗底紫主色/发光玻璃/渐变按钮/科幻感，命中 3 项推倒重来）+ 点击走查（逐个点：按钮有响应、Tab 有切换、跳转通、流程闭环——发现死按钮就补）

## 反模式
- **AI 紫渐变风**：深紫黑底+紫蓝渐变+发光玻璃拟态，AI 生成页面的指纹。暗底禁紫调（色相 260-300 且饱和 >10%）；主色单一全页锁定。
- **死灰硬影**：纯灰中性+纯黑硬投影=脏且廉价。阴影染背景色相、大偏移低透明；中性灰掺品牌色度。
- **灰盒占位框**：「Image」占位块让视觉参考归零。内联 SVG 画场景，或改版式不依赖图片。
- **假数据穿帮**：Lorem/John Doe/99.99% 式整数假数据一行毁真实感；数据要有机且符合业务语境。
- **死按钮假原型**：可点外观不绑行为，用户只能看不能走流程，被迫逐轮返工。交互件必须绑行为且点击有可见结果（切页/浮层/状态翻转/Toast）；无行为元素不得做成可点外观。

## 一个例子
健身 App 周报页：运动绿主色 8-12%、中性掺 2% 绿相、底 #FAFAF9 卡面 #FFFFFF、数据 tabular-nums（47.2%↑）、照片位 SVG 剪影+渐变、卡片 hover 上浮。交互：底栏 Tab 切三屏、分享弹导出弹窗（遮罩可关）、目标卡开抽屉、打卡钮翻已打卡+Toast。AI 味零命中 + 走查全过才交付。
