TraeWork 设计系统

为 AI 工作空间打造的一致、克制的浅色模式界面语言。以 Token 为单一事实来源，让组件、页面与交互在 light-only 的语境下保持清晰可预测。

设计原则

指导每一次布局、配色与交互选择的核心准则。

Token 优先

所有颜色、间距、字号均来自设计 Token，杜绝硬编码与临时取值。

克制用色

品牌紫仅用于主 CTA、当前导航与状态点缀，界面以中性面为主。

字体即层级

通过字号、字重与行高建立信息层级，而非依赖颜色或装饰线。

Quiet Surfaces

卡片与面板使用柔和二级背景，让内容呼吸，避免视觉噪音。

本地图标

统一使用本地 SVG 资产，固定 16px 功能尺寸，保留宽高避免跳动。

无障碍对比

文本与背景保持充足对比度，确保在浅色模式下始终可读。

使用规范摘要

快速核对表，确保页面与组件始终遵循 TraeWork 设计系统。

Light mode only
TraeWork 当前仅提供浅色模式，不引入 dark mode 变量覆盖。

Brand 稀缺使用
--bg-brand 仅用于主 CTA、当前导航项与小状态点缀，避免大面积铺色。

Surface 深度
页面 --bg-base-default，卡片/面板 --bg-base-secondary，悬停/字段 --bg-overlay-l1。

图标尺寸
功能图标默认 16px，紧凑场景 14px，支持性图标 24px；始终保留 width/height。

动效克制
过渡时长控制在 120–180ms，优先使用 opacity 与 transform，避免布局抖动。

无障碍对比
正文与背景对比度满足 WCAG 4.5:1，关键操作不单独依赖颜色传达状态。
